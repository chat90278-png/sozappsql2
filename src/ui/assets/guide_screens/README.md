# Kullanım kılavuzu ekran görselleri

Uygulama içindeki **📘 Kullanım Kılavuzu** ekranı, bu klasördeki PNG görsellerini otomatik olarak yükler.

## Beklenen dosya adları

### Ana ekran ve alt sayfaları

- `ana_ekran.png` — Ana sözleşme listesi ve üst navigasyon
- `yeni_sozlesme_ekleme.png` — Ana ekrandan yeni sözleşme oluşturma akışı
- `platform_yonetimi.png` — Menüden açılan Platform Yönetimi ekranı
- `kullanici_yonetimi.png` — Menüden açılan Kullanıcı Yönetimi ekranı
- `etiket_yonetimi.png` — Menüden açılan Etiket Yönetimi ekranı
- `bilesen_yonetimi.png` — Menüden açılan Bileşen Yönetimi ekranı

### Sözleşme detay ekranı ve alt sayfaları

- `sozlesme_detay.png` — Sözleşme detay ekranı
- `sd_ekleme.png` — Sözleşme detayından SD/alt sözleşme ekleme akışı
- `sistem_ekleme_duzenleme.png` — Sistem ekleme ve sistem bilgilerini düzenleme ekranı
- `kabul_ekleme.png` — Teslimat/kabul kaydı ekleme ekranı
- `sozlesme_silme.png` — Sözleşme silme/onay akışı
- `sozlesme_bilgileri_duzenle.png` — Ana sözleşme bilgilerini düzenleme ekranı
- `etiket_atama.png` — Sözleşmeye etiket atama/kaldırma ekranı

### Diğer kılavuz sayfaları

- `takvim.png` — Takvim ekranı
- `ozet.png` — Sözleşme/sistem özet ekranı

## Önerilen görsel formatı

- Format: PNG
- Önerilen çözünürlük: 1920×1050 ekran görüntüleri için 1280×700
- Görselleri bu klasöre aynı dosya adlarıyla eklediğinizde kılavuz ekranı yeniden açıldığında otomatik görünür.
- Dosya yoksa kılavuzda ilgili bölümde bilgilendirici yer tutucu gösterilir.
